# Nevin Gabriel Prequencia — Portfolio

Dark-themed Next.js portfolio. Content lives in `src/data/profile.ts`.

```bash
npm install
npm run dev
```

## Swap in project screenshots

1. Add images to `public/work` (png or jpg).
2. In `src/data/profile.ts`, update each item in `work`: `image`, `title`, `summary`, and `tags`.
3. Remove the preview note in `workNote` when the slides are real screenshots.

The downloadable resume is `public/Nevin-Gabriel-Prequencia-Resume.pdf`.
